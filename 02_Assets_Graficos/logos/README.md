# Repositorio Oficial de Logos e Isotipos · Mejora Continua

Este directorio contiene los assets vectoriales y en alta resolución del sistema de identidad visual de **Mejora Continua**.

## Archivos Disponibles en este Repo:
* `MC_Logo.png`: Lockup Horizontal Oficial (Isotipo + Wordmark "Mejora Continua").
* `MC1.png` / `MC1A.png`: Variantes de Isotipo "M" en trazo a mano.
* `MC2.png` / `MC2A.png` / `MC2A1.png`: Lockups verticales y aplicaciones en alta resolución.
* `solo-fondo-blanco-miro.png`: Isotipo optimizado para avatares y favicons.

## Reglas de Uso e Invariantes:
1. **Trazo Orgánico:** El isotipo "M" es un gesto a mano alzada. **Nunca se geometriza, no se endereza ni se vectoriza limpiando la imperfección intencional.**
2. **Área de Resguardo:** Margen libre mínimo equivalente a la altura de la "M" del isotipo alrededor de todo el lockup.
3. **Usos Permitidos:**
   * *Lockup Horizontal:* Headers, footers, documentos oficiales, firmas de mail.
   * *Lockup Vertical:* Formatos cuadrados, placas de redes sociales, avatars.
   * *Isotipo Solitarios:* Favicon, app icon, donde el nombre de la marca esté presente en el contexto.
